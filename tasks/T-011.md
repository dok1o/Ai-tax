# T-011 — Offline trilingual Streamlit dashboard
- Owner: arena (Luna). Branch: `arena/T-011-ui`. Owned paths: `app/` and `tests/arena/`. Budget: 8,000 agent tokens.
- Inputs: T-006 dashboard, local T-001 tokenizers, T-004 results and saved T-005/T-007/T-008 models. Output: four Streamlit tabs with Plotly charts.
- Playground: provide independent en/ru/kk text areas. Start in any language and fill the others by hand. Enable “Machine translate” only with explicit `--live` and a key, on button press. Label its output “machine translation, not verified”.
- Show coloured token chips per language with token IDs on hover, token count, tokens_vs_en (count / English count with the same tokenizer) and diagnostic fertility (tokens per word). Show unavailable ratios for missing or zero denominators.
- Compute cost from T-005, error risk from T-007 and the route plus a one-line reason from T-008. Show a disabled placeholder for each missing model. Derive all Playground values from user text, local tokenizers and loaded models.
- Chart token counts across languages for the tokenizer selected in the sidebar.
- 3D: Plotly Scatter3d with x=tokens_vs_en, y=predicted risk, z=predicted cost, colour=language, symbol=category and prompt ID on hover. Plot the router surface with go.Surface (x=threshold, y=saved cost, z=accuracy) from observed evaluation data.
- Label axes with units, put sample size n in each chart title and keep the 2D toggle available for both 3D views.
- Results: show per-language accuracy with CIs, token ratios per language and the router curve against always_direct and always_via_english. Method: show data sources, model versions and query dates, n, native-verified share and limitations.
- Display “EXAMPLE DATA, not real results” whenever any loaded data or model is fixture-derived, including mixed inputs. Clear it for real-only results.
- Acceptance: cold offline start to interactive results <10 s on the demo laptop; one phrase tokenized in <1 s using resources cached with st.cache_resource. Record both timings.
- Tests: cover chip text/IDs, ratios and the Kazakh-specific-letter heuristic as pure functions. Assert figure trace types and encodings; run offline AppTest with and without fixtures, including the banner and missing-model states. Mock live translation to verify both gates.
